Gallery of Shadows — a top-down stealth game: slip past patrolling guards with vision cones, pocket three artifacts on each of three gallery floors, and reach the skylight exit unseen. Hide in the plants, sneak close, and toss a coin to pull a guard away.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Move with WASD or arrow keys, hold Shift to sneak, click to throw a coin, P to pause, M to mute.
